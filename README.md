# Party Political

A classroom tool. Students read policies from the 2024 UK general election manifestos with party names hidden, pick the set they agree with on each topic, then see whose policies they chose.

- `index.html` is the page. Open it in a browser, or turn on GitHub Pages (Settings > Pages > Deploy from branch) to get a link for students.
- `policies.js` holds every policy summary. Edit it to correct or add policies.
- `app.html` is the same page without the outer HTML wrapper, used for publishing as a Claude artifact.

Parties: Conservative, Labour, Liberal Democrats, Reform UK, Green. Summaries are paraphrased; check the full manifestos before relying on a detail.
